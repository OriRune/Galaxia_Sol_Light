# Task 6.1 — Production snapshots and memory accounting

Moved the snapshot design into the authoritative Engine. Snapshots clone every mutable state bank and retain immutable topology/style references. They now also capture style identity counter, pending merger mappings, and new-remnant set alongside records, globals, scheduler accumulators, encounter episodes, and merger effects. Restore clones mutable content, preserves shared immutable styles, restores exact pending state, validates, and intentionally forces playback paused.

Added deterministic snapshot accounting:

- Mutable snapshot bank: exactly 16 bytes/star plus 48 bytes/core.
- Style blocks: five bytes/star, counted once by shared object identity across live state and all snapshots.
- Snapshot count and exact total are exposed for memory gates.

Focused snapshot/engine suites pass 8 tests, including exact digest after restore, pending merger replay, deterministic byte totals, and style lifetime. TypeScript and ESLint pass.
