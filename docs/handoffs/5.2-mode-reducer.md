# Task 5.2 — Mode reducer

Implemented the pure mode transition table before control wiring. It returns next mode, preserve/replace scene result, independent draft, selection, camera event, undoability, and Worker command.

Every same-mode transition is an explicit no-op. Single→Collision/Builder copies the sole configuration into the draft while preserving the scene. Random entry without Generate and Collision/Builder/Random interchanges preserve scene/draft/selection. Every different-mode entry into Single uses selected live galaxy, otherwise first, otherwise draft/new ID; resets center/velocity; retains global setup and playing intent; links draft/selection; enables framing; and returns one undoable `LOAD_SETUP`.

The focused suite exhausts all sixteen from/to combinations and passes TypeScript and ESLint.
