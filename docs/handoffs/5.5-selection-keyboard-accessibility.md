# Task 5.5 — Selection, merger arbitration, keyboard, and accessibility

Wired command-correlated and automatic `SCENE_DELTA` selection arbitration into the shell store. A current null selection wins races, selected merger inputs inherit the remnant, unrelated live selection persists, and removed non-mapped selection clears.

Implemented global shortcut classification with exact interactive-target suppression for fields, native/custom buttons, links, and contenteditable descendants; Space, Period, F, and Escape priority are explicit. Added dialog focus cycling and opener restoration utilities. Controls have programmatic labels, canvas has a low-frequency accessible summary, and the scene overlay key distinguishes center, selection, and velocity.

- Viewport mount now precedes topology/frame application; topology is staged across the mount boundary.
- The application RAF sends Worker ticks directly without React state.
- Application teardown immediately terminates its owned Worker, preventing queued ticks from leaking across scenes/tests.
